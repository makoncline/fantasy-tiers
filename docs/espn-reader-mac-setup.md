# ESPN Reader

## Install once

1. Download `espn-reader.zip`. Unzip it into a folder you will keep.
2. Open `chrome://extensions`. Turn on **Developer mode**.
3. Click **Load unpacked**. Select the folder with `manifest.json`.
4. Pin **Fantasy Tiers ESPN Reader** in Chrome's Extensions menu.

## Draft

Open your ESPN draft. Click ESPN Reader → **Open assistant**.
Keep both tabs open in the same Chrome profile. Make picks in ESPN.

After restarting Chrome or updating the reader, click **Open assistant** again.

## Update or remove

Replace the files in the same folder. Click **Reload** on the reader's card at
`chrome://extensions`. Do this before the draft. To uninstall, click **Remove**.
